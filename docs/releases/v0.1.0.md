# Expanse-X SDK v0.1.0 (Preview)

The SDK preview includes the explicit software core, developer tools and a
Rust/GLSL starter. Rendering and compute run synchronously on the CPU.

## Package refresh

Refreshed on 2026-10-10 with revised project documentation and CLI help. The SDK
version remains 0.1.0. The archive and checksum have both been replaced; download
them together. `BUILD-INFO.json` identifies the source commit and executable hash
for this package.

## Included

- Windows x86_64 MSVC release-built ex.exe and its matching source checkout.
- ex info for adapter/profile/limits; ex doctor for tool readiness and offline
  build checks; ex new for a standalone Rust/GLSL rendering application.
- ex shader build/import/reflect for the bounded EX-GLSL-1 vertex/fragment subset.
- Shader inputs, varyings and uniform reflection, generated EX instructions,
  Cargo incremental shader builds and descriptive unsupported-feature errors.
- Core Preview 1: buffers, command recording/submission, indexed programmable
  graphics, textures/transfers, depth/stencil, blending, compute, bindings and
  explicit whole-resource dependencies, with maintained examples and contracts.

## Download and run

Download expanse-x-sdk-v0.1.0-windows-x86_64.zip and SHA256SUMS.txt from this release.
Verify the ZIP checksum, then extract it into a permanent directory. The archive
includes source dependencies beside bin/ex.exe; keep that directory available.

Install stable Rust, rustfmt, Clippy and the Windows MSVC build/link prerequisites.
Shader compilation also requires glslangValidator and spirv-val on PATH, or
EX_GLSLANG/EX_SPIRV_VAL set to their executable paths. These tools are separate
dependencies and are not bundled or automatically installed.

From the extracted SDK root in PowerShell:

```powershell
.\bin\ex.exe doctor
.\bin\ex.exe new my-ex-app --name my-ex-app
Set-Location my-ex-app
cargo run --locked --offline
```

The starter writes target/ex-starter.png. Edit shaders/triangle.vert or
triangle.frag and rebuild. The archive's SDK-README.md, BUILD-INFO.json and
docs/SDK.md describe setup, provenance and supported behavior.

## Validation and limits

All 272 workspace tests and required formatting/build/strict-lint/Rustdoc checks
pass. The extracted package is verified through version/info/doctor/project
creation, standalone locked/offline build/run and independent checks of every
starter PNG pixel. BUILD-INFO.json records the exact commit, actual tool versions,
target and binary checksum.

This is a preview release, not a stable v1 API. Only the Windows x86_64 binary
package is tested. Rendering runs synchronously on the CPU; there is no GPU driver
or window presentation. GLSL import is restricted to the documented float/vec4
straight-line graphics subset; compute/texture import, branching, loops, matrices
and broader shader-language support are not included. Hand-authored EX IR retains
its existing core operations. Hot reload and broader SDK integrations are future
work. Rust's stable channel is not an exact release compiler pin.

EX adopted the [MIT license](../../LICENSE) after this archive was built. The
existing v0.1.0 ZIP predates that addition; include the repository's LICENSE when
redistributing it. Cargo registry publishing remains disabled.
